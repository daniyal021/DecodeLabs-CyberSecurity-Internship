# Project 4: System Vulnerability Checklist

## Overview
This project focuses on identifying and assessing common system vulnerabilities using a structured security checklist. It demonstrates how to evaluate operating systems, user accounts, software updates, network security, and endpoint protection while applying cybersecurity best practices.

## Objectives
- Perform a basic system security assessment
- Identify common vulnerabilities
- Evaluate password and account security
- Review patch management practices
- Assess network and endpoint security
- Prioritize risks using CVSS concepts
- Recommend security improvements
