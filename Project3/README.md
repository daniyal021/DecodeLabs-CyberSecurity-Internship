# Project 3: Phishing Awareness Analysis

## Overview
This project analyzes emails to identify phishing attempts using a Python-based rule engine and manual security analysis.

## Features
- Detects urgency and phishing keywords
- Identifies suspicious URLs and domains
- Checks sender/domain mismatch
- Classifies emails as **Safe**, **Suspicious**, or **Likely Phishing**

## Files
- `phishing_analyzer.py` – Python source code
- `Project3_Report.pdf` – Project report
- `Sample_Emails/` – Sample phishing and legitimate emails
- `Screenshots/` – Output screenshots
