# Project 2 - Caesar Cipher Encryption & Decryption

## Objective

This project implements the Caesar Cipher algorithm to encrypt and decrypt messages using a user-defined shift key.

## Features

- Encrypt text
- Decrypt text
- Round-trip testing (Encrypt + Decrypt)
- Handles uppercase and lowercase letters

## Technologies Used

- Python 3
